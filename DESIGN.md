# Design

## Theme

Visitors may open the site during a professional review on a laptop in daylight, where the interface needs to feel calm, precise, and easy to scan. Use a light, off-white editorial surface with restrained contrast and one muted accent.

## Color

Use OKLCH tokens. The default strategy is Restrained: tinted neutrals carry the page and a single desaturated olive accent is used sparingly for action, state, and relational markers.

## Typography

Use a premium sans-serif stack led by Satoshi, Geist, and system fallbacks. Display type is confident but not oversized. Body copy stays under 75 characters per line.

## Layout

Prefer asymmetric editorial layouts over centered hero stacks. Use borders, spacing, and typographic hierarchy before cards. Cards are reserved for repeated content previews and case-study modules.

## Components

Core components include Navbar, Footer, SectionHeader, SkillTag, ProjectCard, ExperienceCard, ArticleCard, RelatedContent, MediaGallery, DocumentLink, ExternalLink, Tabs, and reusable CTA buttons.

## Motion

Use subtle CSS transitions, staggered reveal timing, active press feedback, sticky navigation refinement, and reduced-motion fallbacks. Avoid decorative motion that competes with reading.

## Imagery

Use clearly labeled photography placeholders for portrait, hobbies, project covers, and galleries. The image system must make later replacement with real photography simple.
